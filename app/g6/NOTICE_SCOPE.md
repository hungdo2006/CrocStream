# Portable-package notice scope

The ZIP contains a conservative superset of compiled Go notices for the
application and demo relay, the reviewed G0 croc/PAKE/embedded-native
attributions, the Go compiler/runtime LICENSE, and React/Wails runtime notices.
It excludes the Wails CLI, Node/npm, Playwright, TypeScript, relay passwords,
host invitations, pixels, and the Go toolchain binaries. The Go standard library
LICENSE and the separate G0 race-runtime LLVM text are included. Generated
Wails/frontend notices are fingerprinted in `dependencies.json`'s companion
build inventory and the build closeout. This is engineering compliance evidence,
not legal advice or a substitute for counsel reviewing a public distribution.

The package is unsigned and uses a numeric prototype version. Do not publish it
as a production release or imply that Windows SmartScreen reputation exists.
